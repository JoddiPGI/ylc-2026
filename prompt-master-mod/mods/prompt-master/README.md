# Prompt Master

A Claude mod that improves your rough prompt before you send it. It never sends anything: you always press send yourself.

**Use it:** click **✦ Prompt Master** above the prompt box, or type `/prompt-master your rough prompt`. It reads your prompt, asks up to 3 click-to-answer questions (audience, what great looks like, format/length; each with Skip and a type-your-own box), then shows a better prompt (Role, Task, Context, Format, Quality check) above your original with **Use this**, **Edit** and **Keep mine**. It also recommends the best tool (Claude, ChatGPT, Gemini, image or video generator), the lightest Claude model and effort that does the job, and for multi-tool jobs writes one prompt per tool plus a handoff.md you can save.
